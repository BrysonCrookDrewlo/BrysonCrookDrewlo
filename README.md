**Focus for 2026:** bringing self-hosted AI into everyday operations.

## How I work

- **Data stays in-house where it can.** Models run on our own GPUs unless a task genuinely needs an outside service.
- **Every answer cites its source.** A claim that can't point to where it came from isn't shown.
- **Failures are loud.** A broken dependency raises an error instead of falling back silently.
